# 당신의 마흔 번째 계절

사진 없이 타이포그래피, 색, 빛과 인터랙션으로 구성한 마흔 번째 생일 편지 사이트입니다.

## 구성

- 마흔 번째 계절을 여는 인트로
- 클릭해서 하나씩 읽는 사랑의 이유 40개
- 앞으로 함께할 시간을 그린 미래 편지
- 봉인을 눌러 여는 마지막 생일 편지
- 모바일·키보드·모션 감소 환경 지원

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
npm test
```

`npm run dev`, `npm run build`, `npm run start`는 Windows, macOS와 Linux에서 동일하게 동작합니다.
